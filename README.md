# Esimesed skriptid

Tunnis õpetajaga koos tehtud skriptid. 

* ```first.py``` Esimesed katsetused koodi kirjutamisel faili
* ```for_loop.py``` For-loop toimetamised listidega
* ```funktsioonid.py``` Katsetused funktsioonidega
* ```game.py``` Äraarvamise mäng
* ```listid.py``` Kogu inforamtsioon listidest

Õppimiseks kasuta [Progeõpikut](https://progeopik.cs.ut.ee/).
